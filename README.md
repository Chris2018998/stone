Stone is a Java toolkit package integrates three Java pools

🌸[BeeCP](doc/Introduction/beecp_readme_eng.md): A light JDBC Connection Pool

🌷[BeeOP](doc/Introduction/beeop_readme_eng.md): A light Java Object Pool

🌹[BeeTP](doc/Introduction/beetp_readme_eng.md): A light Java Task Pool

## 
:arrow_down: Maven artifact
```xml

<dependency>
    <groupId>io.github.chris2018998</groupId>
    <artifactId>stone</artifactId>
    <version>2.2.2</version>
</dependency>
```
